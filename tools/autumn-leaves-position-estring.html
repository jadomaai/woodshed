Every chord here is built from the same single shape rooted on the low E string — the pattern only ever spans 3 frets (root, one fret back, one fret forward), so there's nothing to relearn per chord, just one shape sliding up and down the neck. No drop-2 spreads, no re-rooting on other strings. Filled dots are core chord tones (root highlighted); the dashed ring on B7♭13 is the optional ♭13 colour tone, on the same string as the 5th — play one or the other, not both. Every chord is rooted on the low E string, using one fixed shape: 3rd/♭3rd one fret toward the bridge from the root on the G string, 5th/♭5th on the B string (5th at the root fret, ♭5th one fret back), and 7th/♭7th/6th on the D string (maj7 one fret forward, dominant/minor ♭7 at the root fret, the 6th one fret back). The A and e strings are never used, so they're always muted. One exception: Em6's root note falls on the open low E string, which doesn't leave room for the 6th degree one fret "back" — so those bars are voiced up at the 12th fret instead (the same open-string pitch, one octave up), where the full shape fits. Every voicing has been verified programmatically against its chord formula. This version genuinely swings across the whole neck — from open position up to fret 11–12 for the D#7 and Em6 bars — because a single fixed shape has to go wherever each chord's root happens to sit on the E string.

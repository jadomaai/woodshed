Movable Interval Patterns — All Six Strings

The original shape roots on the low E string and reads its chord tones off the D, G and B strings. That works so cleanly because of one quirk in standard tuning — the gap between the G and B strings is a major 3rd, not a perfect 4th like every other pair. Root the same idea on a different string and that quirk lands in a different place relative to the root, so the shape stays mostly usable but starts leaking a note or two. Pick a string below to see exactly what each one gives you.

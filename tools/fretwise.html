Accuracy
Play it: the readout names a note and highlights a string — find that note on that string and play it. Fretwise listens through your mic and checks pitch and octave, so it only accepts the note in that string's range. It can't tell which physical string you plucked, so an identical pitch on a neighbouring string will also register — that's the one gap in mic mode.

Read it: a note appears on the staff — no string is hinted, no name is given. Find and play it anywhere on the neck; a ring on the fretboard confirms exactly where it was played, to reinforce what Find by ear teaches. Same mic caveat as Play it above.

Tune: pluck each open string and Fretwise matches it to the nearest string in your chosen tuning, showing how sharp or flat it is so you can bring the guitar to pitch before practising.

Find: pick one or more notes to see every place they sound within the current fret range, on all six strings, each marked with its exact pitch (e.g. D3) in that note's own colour. This mode ignores the strings-in-play filter, since the point is to see the whole neck.

Notes (in Settings): Chromatic includes sharps/flats everywhere in the app; Naturals only restricts the practice target in Play it/Tap it/Read it and the note picker in Find to C D E F G A B.
All pitch detection runs locally in your browser. No audio is recorded or uploaded.
